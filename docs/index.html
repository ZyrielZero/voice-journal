Voice Journal — Privacy Policy

Last updated: November 17, 2026 (version 1.1.0)

Voice Journal is a fully offline application. It is built so that your data never leaves your device unless you export it yourself, and this is enforced by the operating system: the app does not request the INTERNET permission, so it is technically incapable of sending anything over a network.

  • No internet permission, so nothing can be sent anywhere.
  • No accounts, ads, analytics or crash reporting.
  • Recording, transcription and search run on your phone.
  • Your journal leaves the phone only if you export it yourself.

What we collect

Nothing. Voice Journal does not collect, transmit, sell, or share any personal information. There are no analytics, no advertising, no crash reporting, no accounts, and no third-party services of any kind.

Where your data lives

Everything you create — audio recordings, transcripts, and the search index built from them — is stored only in the app's private storage on your device. Recording, transcription and search all run locally. The speech-recognition and search models are included in the app when you install it; the app downloads nothing afterwards.

The journal is excluded from Android's cloud backup and from device-to-device transfer, so it is not copied to a Google account or to a new phone behind your back. The only way it moves is the export described below.

Export and import

You can export your whole journal (audio and transcripts) as a zip file and import it again later, for example to move to a new phone. An export happens only when you start it, and the file goes only to the location you pick in the Android file picker, such as a folder on the device or a cloud-storage app you have installed. From that point the copy is governed by wherever you saved it, not by this app. Import reads a file you choose in the same way. The app itself never sends the file anywhere.

You can set a password when you export. The file is then encrypted on the device (AES-256-GCM, with the key derived from your password) before it is written, and can only be opened with that password. The password is never stored; if you forget it, the export cannot be recovered. Without a password the export is an ordinary, unencrypted zip, and anyone who gets the file can read and play it.

The app lock and "Hide in recents" settings, both on by default, keep other people who are holding your unlocked phone out of the journal and block screenshots of it. They do not encrypt the journal on the device; there it is protected by Android's app sandbox and the device's own storage encryption.

Permissions

The app requests these Android permissions, and uses them only for the purposes listed, never to move data off the device:

  • RECORD_AUDIO: to record the entries you choose to record.
  • FOREGROUND_SERVICE and FOREGROUND_SERVICE_MICROPHONE: so a recording keeps running with the screen off.
  • FOREGROUND_SERVICE_MEDIA_PROCESSING and FOREGROUND_SERVICE_DATA_SYNC: so that a recording interrupted by a crash can finish being transcribed, on the device, the next time you open the app. Despite the second name, nothing is synchronised anywhere: it is the type Android assigns to local file processing on versions before Android 15.
  • POST_NOTIFICATIONS: to show the notification Android requires while recording is in progress.
  • WAKE_LOCK: to keep the processor awake long enough to finish recording and transcribing.
  • USE_BIOMETRIC (and USE_FINGERPRINT on older Android versions): for the optional app lock. The check is done by Android; the app never sees your fingerprint, face or PIN.

None of these permissions allow network access.

Deleting your data

Deleting an entry removes it from the device. Uninstalling the app removes all of its data. Because the app sends nothing anywhere, there is no server-side copy to request or erase. Export files you created are yours to keep or delete wherever you saved them.

Children's privacy

Voice Journal does not collect data from anyone, including children.
