Voice Journal — Privacy Policy

Last updated: October 21, 2026

Voice Journal is a fully offline application. It is built so that your data never leaves your device unless you export it yourself, and this is enforced by the operating system: the app does not request the INTERNET permission, so it is technically incapable of sending anything over a network.

What we collect

Nothing. Voice Journal does not collect, transmit, sell, or share any personal information. There are no analytics, no advertising, no crash reporting, no accounts, and no third-party services of any kind.

Where your data lives

Everything you create — audio recordings, transcripts, and their search index — is stored only in the app's private storage on your device. Recording, transcription, and search all run locally on the device using on-device models. None of it is uploaded, backed up to a server, or made accessible to anyone but you.

Export and import

You can export your whole journal (audio and transcripts) as a zip file and import it again later, for example to move to a new phone. An export happens only when you start it, and the file goes only to the location you pick in the Android file picker, such as a folder on the device or a cloud-storage app you have installed. From that point the copy is governed by wherever you saved it, not by this app. Import reads a zip you choose in the same way. The app itself never sends the file anywhere.

Permissions

The app requests these Android permissions, and uses them only for the purposes listed, never to move data off the device:

  • RECORD_AUDIO: to record the entries you choose to record.
  • FOREGROUND_SERVICE and FOREGROUND_SERVICE_MICROPHONE: so a recording keeps running with the screen off.
  • POST_NOTIFICATIONS: to show the notification Android requires while recording is in progress.
  • WAKE_LOCK: to keep the processor awake long enough to finish recording and transcribing.

None of these permissions allow network access.

Deleting your data

Deleting an entry removes it from the device. Uninstalling the app removes all of its data. Because the app sends nothing anywhere, there is no server-side copy to request or erase. Export files you created are yours to keep or delete wherever you saved them.

Children's privacy

Voice Journal does not collect data from anyone, including children.
